Quick Getting Started

  1. Open this file in your browser (double-click index.html). If responses fail due to CORS, run a local server: python -m http.server 8000 and open http://127.0.0.1:8000.
  2. Type a prompt and press "Run (try public endpoints)". The dashboard will try each prefilled public endpoint until one returns a usable response.
  3. If you find a working endpoint, click "Save" in the right panel to keep it in browser storage and export it to copy into a server-side static/public_spaces.json later (optional).
