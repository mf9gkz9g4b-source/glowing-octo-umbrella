Quick Getting Started

  1. Run the server and open this page: http://127.0.0.1:8000/. Server mode avoids CORS issues.
  2. Type a prompt, choose mode, and press Run. When using server public backend, the server will try endpoints listed in static/public_spaces.json until one works.
  3. To add reliable endpoints: test endpoints here, save them locally, then click "Save to server" and provide the admin token (SAVE_TOKEN) to write to static/public_spaces.json on the server.
